# 🐤 Twitter Clone Full Stack

Projeto full stack desenvolvido com **Node.js, Express, MongoDB** no backend e **React, Redux Toolkit, TypeScript** no frontend.

## 🛠️ Tecnologias Utilizadas

- **Backend:** Node.js, Express, MongoDB (Mongoose), JWT, bcryptjs, TypeScript
- **Frontend:** React, Redux Toolkit, Axios, Lucide React, TypeScript, Vite

## 🚀 Como Executar

### 1. Backend (API)
1. Navegue até a pasta: `cd backend`
2. Instale as dependências: `npm install`
3. Execute: `npm run dev` (rodará em `http://localhost:5000`)

### 2. Frontend (React)
1. Navegue até a pasta: `cd frontend`
2. Instale as dependências: `npm install`
3. Execute: `npm run dev` (rodará em `http://localhost:3000`)
